## Домашняя библиотека

**Стек:** ASP.NET Core MVC, SQL Server, Dapper (только вызовы хранимых процедур), Quill 2 (HTML-редактор оглавления),
HtmlSanitizer (очистка HTML и приведение к XHTML), Bootstrap 5.

**Что умеет:**
- список книг и поиск по названию, автору и тексту оглавления (везде или в выбранном поле);
- карточка книги: просмотр, создание, редактирование, удаление;
- оглавление редактируется в HTML-редакторе и хранится в поле `xml` (`<toc>…XHTML…</toc>`);
- выгрузка оглавления в XML-файл и загрузка оглавления из XML-файла;
- защита от параллельной правки (`rowversion`), валидация полей, защита от XSS и CSRF.

**Хранимые процедуры:** `Book_Insert`, `Book_Update`, `Book_Delete`, `Book_GetById`, `Book_Search`
(`database/02_procedures.sql`). Поиск по оглавлению — XQuery `exist()` по текстовым узлам XML
с первичным XML-индексом, поэтому теги не участвуют в поиске.

### Запуск

Нужны .NET SDK 10 и SQL Server (по умолчанию LocalDB, которая ставится вместе с Visual Studio).

```bash
dotnet run --project src/HomeLibrary.Web
```

Приложение откроется на http://localhost:5256. При первом старте само создаст БД `HomeLibrary`,
выполнит скрипты из `database` и добавит несколько книг для примера. Строка подключения —
`ConnectionStrings:HomeLibrary` в `appsettings.json`. Скрипты можно выполнить и вручную
(в порядке номеров), тогда автоинициализацию отключает `Database:InitializeOnStartup = false`.

### Тесты

## Поиск дублей

```bash
dotnet run --project src/DuplicateSearch -c Release
```

Идея: у `int32` всего 2^32 значений, поэтому заводим битовую карту на 2^32 бит (512 МБ) и за один проход
отмечаем встреченные значения; если бит уже стоит — нашли дубль. Время O(N), `HashSet` не нужен.
